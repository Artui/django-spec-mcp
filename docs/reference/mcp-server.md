# MCPServer

`register_tool` registers a kernel spec as a tool, `register_tools` every spec
in a kernel `SpecRegistry`, and `register_resource` a kernel `RETRIEVE`
selector as a resource. A docstring naming another registrar lands here.
[](){#django_spec_mcp.server.mcp_server.MCPServer.register_service_tool}
